## Mock 引擎设计（demo 的灵魂）

`useAgentEngine()` = module 单例 reactive store，是全部页面共享的单一数据源（messages / tasks / plan / checkpoints / diff / terminal / usage / kpis / experiment / notifications）。

**剧本 = 时间线事件数组**，`dispatch(userText)` 按关键词路由到剧本，逐事件 `await delay()` 推进并应用 reducer：

```ts
type ScenarioEvent =
  | { t: "thinking"; label; ms }
  | { t: "tool"; name; summary; ms; result?; error? }
  | { t: "approval"; title; preview; risk; countdown? }   // ApprovalCard 门，用户决策后续跑
  | { t: "plan"; steps }
  | { t: "stream"; text; cps }        // 打字机吐字
  | { t: "answer"; text; sources }    // AiAnswer（含引用）
  | { t: "checkpoint"; label; files; adds; dels }
  | { t: "diff"; file; oldText; newText } / { t: "terminal"; lines }
  | { t: "usage"; segment; add } / { t: "kpi"; key; push; delta? }
  | { t: "notify"; ... } / { t: "recommend"; ... }
```

**3 个剧本**（关键词触发，任一消息可跑）：
1. **周报生成**（"周报/总结"）：thinking → tools（read_commits/stat_pr）→ stream 回答 + 引用来源 → recommend（开启自动周报）→ usage/kpi 联动
2. **代码修改**（"改/修复/重构"）：plan → tools → **ApprovalCard 门**（risk=medium，30s 倒计时，approve 后继续 / deny 中止）→ diff + terminal + checkpoint → ChangeSummary 汇总
3. **数据分析**（"分析/对比"）：tools → AiAnswer + 图表数据更新 → ExperimentCard 出结论

## 页面 × 组件映射

- **App.vue 壳**：VaAppShell（导航 4 项）+ VaProfileMenu（顶栏）+ VaCommandMenu（**真绑 ⌘K/Meta+K**，命令可跳页/触发剧本）+ VaToaster + 主题切换
- **ChatPage**：VaAgentChat（#composer 接 VaComposer+VaModelPicker）+ 消息内嵌 VaToolCallGroup/VaThinkingLoader/VaAiAnswer（引用角标）+ VaApprovalCard（剧本②）+ VaMessageActions + VaReactionBar + VaSmartRecommendation
- **TasksPage**：VaAgentInbox（任务列表，行展开）+ 右侧 VaFileTree + VaCodeDiff（点文件看 diff）+ VaTerminalLog + VaCheckpointList（恢复→回滚剧本状态）+ VaChangeSummary
- **InsightsPage**：VaKpiChart ×3（运行数/完成数/失败率，任务完成后 push 序列）+ VaBreakdownChart + VaCompactBreakdown + VaExperimentCard + VaContextWindow
- **SettingsPage**：VaSettingsBilling 壳（左导航）→ 分区：VaSetupGuide（上手）+ VaPromptLibrary（点使用→填入 Chat composer）+ VaIntegrationPicker/VaIntegrationSettings + VaUsageMeter + VaPricingPlans + VaNotificationStack（全部已读）+ VaOtpInput（绑定手机演示）+ VaTipsPanel + VaDateRangePicker（账单周期）

未用组件（Motion/插画等）在 Insights/Settings 加一个"展示区"可选——不硬塞。

# 产品定位与架构理念

> Vuagent 是 Vue 3 生态中面向生产级业务系统的嵌入式 Agent 运行时与操作层套件。

传统的 AI 对话组件通常局限于「文本输入框 + Markdown 流式消息」，无法满足真实业务场景中对 **复杂任务执行、高风险操作审批、状态可观测与业务逻辑深度联动** 的要求。

Vuagent 彻底打破了这一局限，围绕三大核心定位构建：

1. **深度贴合业务**：为现有的 Vue 3 系统提供零成本嵌入的 Agent 界面，并支持注入**项目特有的业务工具与自定义 UI 卡片**，实现业务逻辑闭环；
2. **协议优先，端服解耦**：前端流式状态机只依赖标准契约，**只要后端满足协议，即可对接任何自研或开源的 Harness Server**；
3. **工业级开箱即用基座**：自带成熟、稳定、高可靠且易维护的**官方自研 Agent Harness 服务端**，解决网络断线、状态恢复、审批挂起与上下文爆炸等生产痛点。

## 核心定位展开

### 1. 现有 Vue 项目的无缝嵌入与业务扩展

许多团队已经拥有成熟的 Vue 3 后台管理系统、SaaS 平台或业务门户。Vuagent 的核心使命之一，就是让这些存量项目在几天内平滑升级为具备自主执行能力的 AI Agent 系统：

* **开箱即用的前端交互**：提供 `VaAgentChat`（对话骨架）、`VaAppShell`（应用外壳）以及核心逻辑 Composable `useAgentChat`，零配置拉起多会话、流式回复与交互面板。
* **双通道自由分发**：支持 `npm i @vuagent/ui` 整包引入，也支持 shadcn-vue 式的单文件源码拷贝。peer 仅依赖 `vue ^3.5`，零额外重型依赖。
* **业务专属工具（Tools）接入**：宿主应用可以定义属于自身业务的 Tool Schema（例如：`refund_order` 退款审批、`create_k8s_cluster` 创建集群）。
* **业务专属 UI 卡片动态挂载**：通过组件动态渲染分发器（`VaAgentRenderer`），开发者可以将业务 Vue 组件注册到运行时。当大模型触发特定工具或状态时，前端原地渲染专属业务卡片，用户可以在卡片上操作、表单填写并回传给 Agent。

---

### 2. 协议优先、端服解耦：对接任意 Harness Server

Vuagent 坚守「**界面与执行解耦**」的架构哲学。前端不是任何单一云服务或私有后端绑定的壳：

* **单一事实来源契约（`@vuagent/protocol`）**：
  * 全链路基于 TypeBox 契约定义，包含完整的 **18 个判别联合 SSE 事件流**（涵盖轮次生命周期、思考链、文本增量、工具调用四段式、UI 卡片渲染、Token 水位、可观测轨迹）。
  * 包含标准的 **HITL（Human-in-the-Loop）动作回传契约**（`/api/action/:id`）。
* **多语言与自定义后端无缝适配**：
  * 无论是使用 Python（基于 LangChain、LangGraph、AutoGen、CrewAI 自研）、Go、Java 还是其它技术栈搭建的 Agent Harness，**只要其 SSE 输出符合 `@vuagent/protocol` 规范，即可直接驱动 `@vuagent/ui` 前端界面**，无需重写任何前端状态机与卡片渲染器。

---

### 3. 成熟、稳定、可维护的官方 Harness Server

针对希望省去搭建底层 Harness 成本的团队，项目内置了开箱即用的 `@vuagent/server`。它是经过严苛设计的生产级执行引擎：

* **执行与 HTTP 连接彻底解耦**：
  * Agent 任务在服务端的会话枢纽（`SessionExecutionHub`）内独立持续运行。
  * 用户切出页面、关闭浏览器、或移动端网络中断，**后台任务不会中断**；重新连接时，通过内置事件缓冲区增量重放（带 `seq` 序号去重）。
* **诚实的状态恢复与崩溃自愈**：
  * 关键执行轮次与快照事务级落库（支持 SQLite / Redis）。
  * 即使服务意外重启，未决任务与审批现场也可诚实恢复，拒绝状态黑盒。
* **真·协程级 HITL 审批挂起**：
  * 当模型触发高风险工具时，执行协程自动挂起（Promise 语义）并广播审批事件；用户通过 HTTP 回调唤醒，支持超时自动熔断，无需低效的前后端轮询。
* **严谨的 Token 预算与上下文治理**：
  * 采用真实 Token 口径统计与滑动窗口机制，配合历史会话自动摘要折叠与占位，彻底规避上下文无限膨胀导致的性能雪崩与成本失控。
* **供应商 1:N 模型解耦与能力自适应**：
  * 支持 OpenAI 兼容及 Anthropic 原生驱动，统一抽象凭证与模型分层管理；
  * 保守启用高级能力（推理档位、多模态附件、缓存折扣分档计价）。

## 总体架构与数据流向

```text
                  @vuagent/protocol — 单一事实契约层 (TypeBox)
                 /                                            \
    工具 Schema + 18 判别事件流规范                      组件生命周期模型与渲染接口
                 │                                             │
                 ▼                                             ▼
       Harness Server 服务端                                前端应用层
   ┌───────────────────────────┐                 ┌───────────────────────────┐
   │ 官方 @vuagent/server 或    │                 │ 宿主 Vue 3 项目            │
   │ 任意符合协议的自定义后端   │                 │                           │
   │ (Python/Go/Java)          │                 │ 73+ 运行时组件 (@vuagent/ui)│
   │                           │                 │ 业务专属 UI 卡片           │
   │ ReAct 循环 · HITL 挂起    │                 │ useAgentChat 流式状态机    │
   │ 工具沙箱 · 崩溃恢复       │                 │ VaAgentRenderer 动态分发器 │
   └─────────────┬─────────────┘                 └─────────────▲─────────────┘
                 │                                             │
                 │ 1. 下行 SSE 事件流（18 种事件类型）          │
                 ├─────────────────────────────────────────────┘
                 │
                 │ 2. 上行 POST /api/action/:id（用户决策与卡片交互唤醒）
                 ▼
```

### 一次交互的典型生命周期

1. **发起任务**：宿主前端通过 `useAgentChat()` 向 Harness 服务端发起执行请求；
2. **渐进推理**：服务端进入 ReAct 循环，向前端推送 `thought_delta`（思考过程）与 `text_delta`（文本正文）；
3. **工具调用与卡片渲染**：模型发起业务工具调用时，下发 `tool_call_start` 与参数增量。前端 `VaAgentRenderer` 匹配已注册的业务卡片，进行骨架屏或渐进渲染；
4. **人工审批中断（HITL）**：遇到高风险操作，服务端挂起协程并下发 `suspended` 事件；前端渲染审批卡片，用户点击批准或驳回，动作经 `/api/action` 回传，服务端协程被立即唤醒继续执行；
5. **任务收敛**：执行完成，下发 `usage`（Token 用量分段统计）与 `turn_end` 广播，完成全链路闭环。

## 三包职责与选型建议

| 模块 | 包名 | 职责 | 适用人群 / 场景 |
| :--- | :--- | :--- | :--- |
| **契约层** | [`@vuagent/protocol`](/protocol/overview) | 定义全链路共享的 TypeBox Schema、18 种流式事件、工具声明与生命周期。 | 所有开发者、以及希望自研 Harness 服务端的团队。 |
| **界面层** | [`@vuagent/ui`](/guide/getting-started) | 提供 73 个 Agent-Ops 组件、流式状态机、动态渲染分发器与样式令牌。 | 需要在 Vue 项目中构建 Agent 页面或嵌入卡片的工程师。 |
| **执行层** | [`@vuagent/server`](/server/overview) | 官方自研生产级 Agent Harness：ReAct 循环、断线重连、HITL 挂起、上下文治理与模型驱动。 | 需要即插即用、开箱可落地的工业级 Agent 后端服务的团队。 |

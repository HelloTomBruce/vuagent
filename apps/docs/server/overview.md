# 官方 Harness Server 架构总览

> `@vuagent/server` 是专门为解决企业生产级痛点而打造的 Agent Harness 执行引擎。它基于 TypeScript 和现代异步机制，以 ReAct 循环驱动大模型与工具的协作，内建连接解耦、HITL 审批挂起、工具沙箱、崩溃自愈与双轨可观测性。

---

## 总体架构设计

服务端采用洋葱分层架构，清晰地划分为准入层、调度枢纽、核心循环、工具闸门和模型驱动层，横切存储、配置中心与安全基线：

 └──────────────────────────────────┬─────────────────────────────────────┘
                                    │
 ┌──────────────────────────────────▼─────────────────────────────────────┐
 │ 2. 会话执行枢纽 (SessionExecutionHub)                                   │
 │    ★ 执行与 HTTP 连接解耦 · 后台持续执行 · 事件重放环形缓冲 · 多端同步订阅     │

                                    │
 ┌──────────────────────────────────▼─────────────────────────────────────┐
 │ 3. ReAct 主循环 (AgentLoop)                                            │
 │    参数解析 ➔ 上下文组装 ➔ [模型流式推理 ➔ 工具执行段 ➔ 结果喂回] × N ➔ 收尾  │

## 一次对话的完整生命周期

当一次 Agent 请求发起时，服务端经历严格的 5 个阶段：

1. **准入门禁**：通过安全基线检查（鉴权、Origin 校验）➔ 会话并发仲裁（同会话正在运行时进行拒绝或平滑顶替）；
2. **持久化初始行（Running）**：执行前立即入库打标，即使进程遭遇突发断电或宿主重启，重启后也能诚实地将其标为异常中断并恢复历史，拒绝伪状态；
3. **ReAct 循环回环**：
   * 组装上下文（注入系统提示、工具定义、历史消息及 Token 水位截断）；
   * 驱动模型流式输出（`thought_delta` 思考链与 `text_delta` 正文）；
4. **工具守卫段（每步）**：
   * **启停仲裁**：被禁用的工具自动从模型视图中剔除；
   * **工作区闸门**：只读目录拦截写工具；
   * **权限交集判定**：高风险操作触发 **HITL 审批协程挂起**，等待前端确认；
   * **沙箱执行**：入参经 TypeBox 运行时校验，超时竞速执行，并将结果就地喂回上下文；
5. **终态收敛**：替换 running 为完成态，记录精确的 Token 消耗与成本，下发 `turn_end` 广播。

## 供应商 1:N 模型分层架构

针对企业内接入多个模型、多个密钥频繁维护的痛点，服务端设计了 **供应商（Provider）与模型档案（Model Profile）解耦** 的两层模型：

```text
 供应商 (ProviderEntity)  ─── 1:N ───  模型档案 (ModelProfileEntity)
 (端点 baseUrl / 凭证明文 apiKey)      (模型名称 / 上下文窗口 / 推理档位 / 模态)
```

* **凭证配置一次，处处生效**：修改 Provider 的 API Key，其下所有模型（如 DeepSeek-V3、DeepSeek-R1）立即全部同步，模型本身不硬编码 Key；
* **能力探测（Discover）**：支持一键调用 `GET /api/settings/providers/:id/models/discover`，服务端代发端点探针，自动探测模型的上下文窗口、视觉模态与推理能力；
* **能力驱动运行时（保守策略）**：只有档案声明了对应能力，服务端才会在请求中携带高级参数（如推理深度 `reasoning_effort`、多模态图片、Token 缓存等），杜绝盲目猜测导致的调用报错。

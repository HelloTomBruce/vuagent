Vuagent · Brand Mark

V 轨迹 — 一笔写完 Agent 的一生

标识由一条 Agent 执行轨迹构成字母 V(Vue · Vuagent)。 左笔画是虚线的计划,途经橙色审批门后变为实线的执行,最终抵达完成的端点 —— 这正是 Vuagent 组件库所操作的 Agent 运行时:计划、审批、执行、结果。

01概念解析:四个部件,一句话故事

每个部件都对应 Vuagent 的一个 Agent-Ops 组件域 —— 标识即产品地图。

计划 plan → do

VaAgentPlan

虚线:从用户的请求(左上)开始,以「提议」的姿态一段段铺向审批门 —— 还没发生,但已可见。

审批门 approval gate

VaApprovalCard

V 的顶点 = 力量汇聚处。开放的圆环是危险操作前的「等待人工放行」。

执行 → 完成 execution → done

VaTrajectory

越过审批门,虚线变成实线:提案已成为事实。橙色端点 = 交付结果。

06使用守则

✓ 这样用

  • 保持四部件完整:计划虚线、审批环、执行实线、端点,不可增删
  • 净空区:标识四周留出 ≥ 1/4 标识高度的空白
  • 最小尺寸:主标 24px 起,favicon 版 16px 起
  • 只允许纸底亮色 / 墨底暗色两套官方配色
  • 动效仅按 hero 区的方式整段描画,尊重 prefers-reduced-motion

✗ 不要这样

  • 不要旋转、倾斜、加投影或描边
  • 不要把虚线改成实线、把审批环填充实心
  • 不要替换为渐变色 / 霓虹色 —— 保持「暖纸 + 烧橙」的手作气质
  • 不要拉伸变形,缩放请等比
  • 不要在标识周围加竞争性的强色块
